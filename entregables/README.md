# Entregables

Lo que ya está terminado y sale hacia afuera: informes entregados, presentaciones dadas, documentos
enviados.

Separarlo de `proyectos/` tiene una razón práctica: aquí solo hay versiones finales. Cuando busques
"el informe que entregué", no vas a encontrar siete borradores al lado.

Nombra los archivos con la fecha adelante, para que se ordenen solos:

```
2026-09-03-informe-fuente-conmutada.pdf
2026-10-15-presentacion-electronica.pdf
```
