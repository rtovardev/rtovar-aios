# Universidad

Una carpeta por materia. Adentro va todo lo de esa materia: el programa, las guías del profesor,
tus apuntes, los PDF, los laboratorios.

```
universidad/
├── circuitos-2/
│   ├── programa.pdf
│   ├── apuntes.md
│   └── laboratorios/
└── electronica-1/
```

**Por qué importa que estén aquí adentro:** el agente puede leerlos. En vez de subir un PDF a un
chat cada vez, le dices *"según la guía de Circuitos II"* y él la busca. Y si le pides que estudie
contigo, tiene el material real y no lo que recuerda de internet.

Nombra las carpetas en minúsculas y con guiones: `circuitos-2`, no `Circuitos II`.
