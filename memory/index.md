# Índice de memoria

Todo lo que el agente debe recordar entre conversaciones está aquí, enlazado. OpenCode carga este archivo en cada sesión.

**Regla:** una página por tema. Si una página crece demasiado o mezcla dos cosas, pártela. Si algo no está enlazado desde este índice, para el agente no existe.

## Cómo crecer esto

Cuando aparezca algo que valga la pena recordar, pide «guarda esto en memoria», o corre `/cerrar-sesion` al terminar el día. El agente crea la página en `wiki/`, la enlaza aquí y te dice qué guardó.

**Qué sí guardar:** decisiones y por qué se tomaron · datos estables (horarios, fórmulas, requisitos de un profesor) · cómo funciona algo que te costó entender · el estado de un proyecto.

**Qué no guardar:** conversaciones completas · contraseñas o claves · datos personales de terceros · cosas que cambian cada semana.
