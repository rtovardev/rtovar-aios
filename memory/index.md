# Índice de memoria

Todo lo que el asistente debe recordar entre conversaciones está aquí, enlazado.

**Regla:** una página por tema. Si una página crece demasiado o mezcla dos cosas, pártela.
Si algo no está enlazado desde este índice, para el asistente no existe.

## Páginas

- [Ejemplo: cómo se escribe una página](wiki/ejemplo.md)
- [Ejemplo: una página que enlaza a otra](wiki/ejemplo-proyecto.md)

## Cómo crecer esto

Cuando aparezca algo que valga la pena recordar, pídele al asistente:

```
Guarda esto en memoria
```

Debe crear la página en `wiki/`, enlazarla aquí y decirte qué guardó.

**Qué sí guardar:** decisiones y por qué se tomaron · datos estables (horarios, fórmulas, nombres de
profesores) · cómo funciona algo que te costó entender · el estado de un proyecto.

**Qué no guardar:** conversaciones completas · contraseñas o tokens · datos personales de terceros ·
cosas que cambian cada semana.
