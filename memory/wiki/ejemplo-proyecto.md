# Ejemplo: una página que enlaza a otra

Esta página existe para mostrar lo que la anterior solo describe: **cómo se conectan las páginas
entre sí**. Bórrala junto con la otra cuando escribas las tuyas.

## Resumen

Cuando un tema se relaciona con otro, no lo repitas: enlázalo. Así el asistente sigue el hilo solo
y tú no mantienes la misma información en dos sitios.

## Cómo se enlaza

Con un enlace de Markdown normal, relativo a esta carpeta:

```markdown
El formato de estas páginas está explicado en [la página de ejemplo](ejemplo.md).
```

Que se ve así: el formato de estas páginas está explicado en [la página de ejemplo](ejemplo.md).

## Por qué importa

Una página suelta es una nota. Varias páginas enlazadas son una memoria: el asistente entra por
`index.md`, encuentra la que necesita y desde ahí llega a las demás sin que tú se lo digas.

**Regla:** cada página nueva se enlaza desde `index.md`. Si además se relaciona con otra, enlázalas
entre sí.
